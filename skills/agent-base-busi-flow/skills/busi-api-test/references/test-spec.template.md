# TEST-SPEC 模板（三段式）

> 本文件被 [busi-api-test/SKILL.md](../SKILL.md) 阶段 3.1 引用作为 `01-{需求}-TEST-SPEC.md` 的输出格式骨架。

---

```markdown
# {需求} TEST-SPEC

## 一、链路总览
（阶段 1.3 链路图 + 数据依赖 + 角色切换点）

## 二、关键决策
（阶段 2 拷问结论：前置数据 / 鉴权 / 失败模式断言精度）

## 三、用例矩阵

| # | 链路名 | 类型 | 数据依赖 | 鉴权角色 | 预期结果 | 来源（B5 §几）|
|---|---|---|---|---|---|---|
| 1 | 主流程 happy path | 正向 | xxxId 来自接口 1 | 角色 A | 200 + yyyId | §九正向 |
| 2 | 重复提交幂等 | 边界 | 复用 1 的数据 | 角色 A | 200 + 同 yyyId | §七并发 |
| 3 | 终态再操作 | 异常 | 1 完成后强改状态 | 角色 A | 400 + 错误码 X | §七并发 |
| 4 | 跨角色权限校验 | 异常 | 1 完成后切角色 | 角色 B | 403 + 错误码 Y | §七权限 |
| 5 | 历史数据兼容 | 兼容 | 灰度前历史数据 | 角色 A | 200 + 容忍 null | §七历史 |
| 6 | 批量上限 | 边界 | 构造 N+1 条 | 角色 A | 400 + 上限提示 | §九性能 |
```

## 用例覆盖矩阵硬约束

| 类型 | 必须有 |
|---|:--:|
| 正向 happy path | ✅ |
| 边界（空 / 单 / 上限） | ✅ |
| 异常（B5 §七 6 类至少 3 类） | ✅ |
| 兼容（历史数据 / 旧版本前端） | ✅ |
| 跨需求回归（本版本影响的历史接口） | ✅ |

任一缺失 → TEST-SPEC 不合格，重写。
