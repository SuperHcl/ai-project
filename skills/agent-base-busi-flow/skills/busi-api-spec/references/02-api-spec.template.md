# 接口文档模板

> 本文件被 [busi-api-spec/SKILL.md](../SKILL.md) 步骤 4（落地阶段）引用作为输出格式骨架。
> AI 落地 `iterate/v{版本}/{业务模块}/02-接口文档-内部.md` 或 `02-接口文档-外部.md` 时，按本模板填充。

---

## 内部接口文档模板

```markdown
# {需求名} 内部接口文档

> 来源：本文件由 `01-需求内容.md` 第 N 节涉及接口表展开生成。

## 接口概述

{该模块本次涉及的接口的总体说明，2-3 句话}

## 接口列表

### 1. {接口中文名} 【v{版本} 新增/修改/删除】

- **归属服务**：{服务名}
- **请求方式**：GET / POST / PUT / DELETE
- **请求路径**：`/xxx/yyy/v1/zzz`
- **鉴权**：{前端登录 / Feign 内部 / 对外公开}
- **变动说明**：{本版本相对历史的差异，1-2 句}

**请求参数**：

| 字段 | 类型 | 必填 | 说明 | 版本 |
|---|---|:--:|---|:--:|
| pageNo | Integer | 是 | 页码，从 1 开始 | - |
| status | Integer | 否 | 状态筛选 1=启用 0=停用 | v{版本} 新增 |

**响应结构**：

​```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "records": [...],
    "total": 0
  }
}
​```

**响应字段**：

| 字段 | 类型 | 说明 | 版本 |
|---|---|---|:--:|
| records[].id | Long | 记录主键 | - |
| records[].isRead | Integer | 是否已读 1=已读 0=未读 | v{版本} 新增 |

**业务逻辑摘要**：

1. {一句话步骤 1}
2. {一句话步骤 2}

**调用链路**：Controller → Service → Mapper（仅在跨服务/Feign 调用时标注）

**错误码**：

| 错误码 | 含义 |
|---|---|
| 40001 | 参数缺失 |
| 40301 | 无权限 |

---

### 2. {下一个接口}
```

## 外部接口（Feign）模板

外部接口（Feign）模板基本一致，**额外标注**：

- 接口类全限定名（如 `com.xxx.feign.api.InnerOrderApi`）
- 接收端 Controller 类名（用于 Feign-back-controller 模式）
- 跨服务调用时的版本兼容策略（消费方未升级会怎样）
